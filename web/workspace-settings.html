作用域说明

空间设置仅对当前工作区内新建或续跑的任务生效，点击底部「保存」持久化配置。

基本信息

工作区目录

工作区显示名称与本机目录路径；任务默认运行目录（cwd）取自此处。

Git 状态

只读探测

只读查看此路径下的全部 Git 仓库（工作区根目录、嵌套仓库及子模块），不会提交、推送或切换分支。

空间提示词

首轮注入

首次启动本空间任务时自动前置拼接到用户 prompt（已有会话的续跑不重复注入）。

Skills

按行配置

每行填写一个 skill 名称或路径。启动任务时写入 prompt 提示；原生 skill 目录注入视各 Agent CLI 能力而定。

MCP

覆盖全局同名配置

填写 mcpServers JSON，保存后在各 Agent 下次新建或继续任务时加载。支持 command/args/env 和 url/headers；纯文本仅作为提示词说明。

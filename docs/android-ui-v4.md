# Android UI · Figma Make v4

设计来源：[ThinkBook APK UI v4 · 任务搜索 · 配对断开](https://www.figma.com/make/QNbNv8Fr0hJXPNGSGRaSTg)。本次直接读取 Make 预览的 DOM、CSS 和交互，再实现为 Jetpack Compose。视觉以这版设计为准，替代旧方案仅对齐信息结构的要求。

`ui/Theme.kt` 管理颜色和字体；`ui/Components.kt` 管理原型线条图标、表单、按钮、状态和卡片；`ui/Screens.kt` 负责页面布局与现有 ViewModel 操作绑定。

任务列表使用工作区下拉、状态标签、工作区内任务搜索和卡片。详情按标题、操作、对话轮次、任务信息、原始日志排序。其他页面包括分组工作区设置、看板设置、新建任务、多看板列表和添加 / 配对表单。短暂通知使用 Snackbar，避免挤动内容。

## 真实数据与原型的差别

- Android 系统栏、字体、键盘和屏幕边界随设备变化，不绘制原型中的假时间、电量或手机边框；尊重系统字体缩放。
- 归档仍是单独的只读列表，不把原型的归档示例混入热任务列表。截断、加载失败、离线、能力限制及幂等命令恢复继续显示真实状态。
- 新建任务标题仍为协议要求的必填项；工作目录保留可编辑。续跑需要填写提示词，原型中直接显示“已继续”的演示不用于真实操作。
- 看板设置读取并保存真实 CLI 路径、四项代理变量、Codex 沙箱和快捷提示词。Cursor 使用服务端的 `agent` 键。代理脱敏占位值原样提交，让服务端保留密码；不记录或持久化未提交的表单。
- 工作区 Git 卡片显示服务端返回的只读摘要。没有数据时不生成分支、干净状态或仓库数量。
- 原型示意的“默认模型”和“全局代理”没有对应看板配置，保留说明文字。

## 验证

2026-11-01：JDK 17、Android SDK 35 下执行：

```bash
cd android
./gradlew :app:assembleDebug :app:testDebugUnitTest :protocol:test :app:lintDebug
```

131 项单元测试通过；Lint 无错误。新增测试验证不完整或类型错误的设置响应不能变为可编辑配置，以及写入保留脱敏代理、Cursor 键名和关闭沙箱状态。

Android 11 模拟器使用本地测试中继验证配对、任务搜索和清除、详情、工作区设置、看板设置读取与保存、新建和续跑表单。截图使用测试数据，不连接生产看板。

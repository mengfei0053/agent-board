添加看板

为新看板签发专属 BOARD_TOKEN，不会影响已连接的其他看板。把下方配置填到看板所在机器后重启看板，连上后会自动出现在上方列表。

以字母或数字开头，只能包含字母、数字、点、下划线和短横线，最长 64 字符。

生成手机配对码

一次性使用，默认 5 分钟有效，实际有效期由服务配置决定。支持离线看板。

多个 ID 用英文逗号分隔，最多 20 个。

轮换看板令牌

为已有看板更换 BOARD_TOKEN（例如令牌泄露）。新增看板请用上方“添加看板”。

会撤销通用初始令牌及覆盖任意所填 ID 的旧令牌，可能使其他看板一起断线。请先确认迁移计划。
